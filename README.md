# fhir-pipeline — FHIR R4 patient records on Databricks

Synthetic FHIR R4 patient records, from nested JSON bundles to analytics-ready
tables, on Databricks: bronze (raw bundles) -> silver (one flat table per FHIR
resource) -> gold (analysis tables), with quarantine, gates and measured numbers.

**Dataset:** Databricks Marketplace, "FHIR R4 Synthetic Data" (free, by Databricks),
notebook "FHIR R4 Read with SQL". Generated by [Synthea](https://synthea.mitre.org):
fake but realistic patients. **Not real people, not real health statistics.**

**Status:** set-up. Nothing built yet. Scope and decisions: `docs/report/scope_and_gaps.md`.

Built on the structure of the BRFSS project (`osamagul08/data-eng`, tag `v1.0`).

## Layout (will grow)
```
CLAUDE.md                 rules for the AI assistant: never invent numbers, verify, explain
scripts/common/           shared login + SQL runner (from the BRFSS project)
sql/databricks/           transform/ (the logic) and checks/ (run by hand)
resources/, src/          Databricks bundle resources and pipeline code (to come)
docs/report/              scope_and_gaps, later metrics and the manager report
docs/learning/            learning log, Claude playbook, Power BI prompt
docs/reference/           listing notebook (local only, git-ignored)
```

## Setup
```powershell
python -m pip install -r requirements.txt
copy .env.example .env      # then fill in your Databricks values
databricks auth login --host <workspace URL> --profile trial
```
